Technical Guide

How the Patrol Grid Visit Workflow is built: the data ingestion pipeline, how the coverage grid and per-cell metrics are calculated, and how the map and dashboard are assembled.

Download the full Technical Guide (PDF) v1.1

Version 1.1 documents workflow version 1.0.0. The segment filter is now configured as an advanced field of the Relocations To Trajectory step, with the permissive ecoscope-platform defaults (100 km, 48 h, 500 km/h), and the guide adds workflow details and authorship. Version 1.0 documented the workflow on ecoscope-platform 2.18.0 and ecoscope-workflows-ext-mnc 1.0.5.
